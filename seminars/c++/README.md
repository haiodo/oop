# Семинары курса ООП (C++)

Материал для преподавателя: порядок семинаров и привязка к задачам из
[`../../cpp-tasks/`](../../cpp-tasks/). Сами слайды этой информации не содержат.

Слайды в формате [Marp](https://marp.app/).

## Просмотр и сборка

Нужен `marp-cli`: `npm i -g @marp-team/marp-cli`.

```bash
make                    # список презентаций и targets
make serve              # все презентации в браузере, с автообновлением при правке
make s05_move_smartptr  # собрать одну и открыть в браузере
make html               # собрать все в build/
make pdf                # то же в PDF, с оглавлением
make clean
```

`make serve` поднимает http://localhost:8080 со списком всех файлов и
перерисовывает слайд при сохранении - основной режим при подготовке к паре.
Порт меняется через `make serve PORT=9000`.

Альтернатива без сборки - расширение "Marp for VS Code": открывает превью
прямо в редакторе.

## Что чем закрывается

Семинары привязаны к пунктам зачёта, а не к темам вообще. Если семинар
переставить или пропустить, соответствующая задача становится невыполнимой.

- **Задача 1a** - раздельная компиляция и пространства имён: семинар 1 целиком.
- **Задача 1b** - разбор байтов (`char` и `<cctype>` - UB), детерминированная
  сортировка с тай-брейком, проценты через `setprecision`, счётчики
  на `map`/`unordered_map`: семинар 2.
- **Задача 2** - rule of five, инвариант неиспользуемых битов, `-Wsign-conversion`,
  исключения по видам ошибок: семинары 3 и 4; move-операции, copy-and-swap,
  сильная гарантия, COW: семинар 5.
- **Задача 3** - `unique_ptr` и срезка: семинары 5 и 6; запрет проверок типа
  в движке: семинар 7; инвалидация итераторов при мутации контейнера во время
  обхода и фиксированный шаг на `steady_clock`: семинар 8.
- **Задача 4** - разбор RIFF, пропуск посторонних чанков, потоковая обработка:
  семинар 9; реестр конвертеров, справка из реестра, двухфазность
  (проверка конфигурации до обработки), коды возврата: семинар 10.
- **Задача 5** - шаблоны и модель компиляции: семинар 11; вывод `std::tuple`
  и ловушка с ADL: семинар 12; InputIterator и постфиксный `++`: семинар 13;
  `if constexpr` для ветки `std::string`: семинар 14.

## Правила для правок

Код на слайдах студенты копируют дословно, а потом гоняют через `clang-tidy`
и сборку с предупреждениями как ошибками. Поэтому:

- имена по `../../cpp-tasks/GRADING.md` §6: типы `CamelCase`, функции и методы
  `lower_case`, поля `lower_case_`, константы `kCamelCase`;
- всегда явный `std::`, никаких `using namespace std;`;
- каждый пример обязан компилироваться под C++20;
- антипаттерн на слайде допустим только с подписью и правильным вариантом рядом;
- никаких упоминаний о том, что и когда спросят на приёме.
